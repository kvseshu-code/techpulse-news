# TechPulse Production Launch Checklist

- [ ] Company-owned custom domain
- [ ] CDN/WAF and DDoS protection
- [ ] HTTPS validated
- [ ] HSTS enabled after validation
- [ ] CSP/security headers applied at edge
- [ ] No secrets/API keys in frontend
- [ ] GitHub Actions permissions minimized
- [ ] Third-party Actions pinned to immutable SHAs
- [ ] Dependency/secret scanning
- [ ] Last-known-good dataset rollback tested
- [ ] Feed failure and malformed RSS tests
- [ ] CDN cache test
- [ ] Load test against public CDN URL
- [ ] Monitoring and alerting
- [ ] Correction contact
- [ ] Security reporting contact
- [ ] Legal/policy review before commercial launch
